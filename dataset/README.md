# Dataset Information

The data files in this directory are sourced from the official Kaggle Competition:
**Store Sales - Time Series Forecasting**
URL: https://www.kaggle.com/competitions/store-sales-time-series-forecasting/data

### Files:
- `train.csv` (121.8 MB - Primary historical sales data; excluded from Git tracking due to GitHub's 100MB limit)
- `test.csv` (Competition test split)
- `stores.csv` (Store locations, types, and clusters)
- `oil.csv` (Daily WTI crude oil price)
- `holidays_events.csv` (National, regional, and local Ecuadorian holidays)
- `transactions.csv` (Daily store transaction footfall)
- `sample_submission.csv` (Competition submission format)

To re-run the full pipeline from raw data, download `train.csv` from Kaggle and place it in this directory.
